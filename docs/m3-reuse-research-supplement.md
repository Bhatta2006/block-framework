## Opinionated recommendations (the short list)

1. **LLM layer:** Vercel AI SDK (`ai` + `@ai-sdk/openai-compatible` for OpenRouter/local models; add `@ai-sdk/anthropic`/`@ai-sdk/google` when needed) behind our own `AgentGateway` interface. Recorded-response provider = a `LanguageModelV2`-compatible stub returning fixtures (deterministic, offline).
2. **Schemas/validation:** `zod` for edit-op schemas + AI SDK structured output; `ajv` (already in tree) to validate agent output against manifest JSON Schemas; `p-retry` for the bounded retry loop.
3. **Diff/undo:** `immer` `produceWithPatches` as the single primitive (undo = inverse patches; change log = forward patches), `microdiff` for computing the human-facing change list, custom renderer for the demo UI. `diff` (jsdiff) only for free-text fields.
4. **Live preview:** esbuild incremental rebuild + iframe reload via `postMessage`. No new dependencies.

**Lock-in notes:** the AI SDK is the only pick with real API churn risk (v5→v7 renames); the mandatory `AgentGateway` wrapper contains it. Everything else is small, stable, MIT/BSD/ISC/Apache-2.0, and replaceable in an afternoon. No GPL/AGPL anywhere near the REUSE list; the single unclear license found (`multi-llm-ts`, missing license field) was rejected.
